## lpalign --- [<i class="fa-brands fa-github"></i> git link](https://github.com/jfravel/lpalign)

This is a LaTeX package which simplifies the typesetting of mathematical programs by emulating amsmath's alignment environments with a load of formatting features and without any the extra spacing characters. See the example below!

![Image](/assets/lpalign.png)

It has not yet been added to CTAN, so it will need to be added to your project directory manually. (Don't worry; it is quite simple!)
